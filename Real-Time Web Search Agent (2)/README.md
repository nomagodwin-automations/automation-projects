# Real-Time Web Search Agent

This folder contains the Real-Time Web Search Agent and its project documentation together.

## Files

- `Real-Time Web Search Agent (2).json` — the workflow export for this automation.
- `README.md` — overview of how the workflow operates.

## What it does

- Receives Telegram user messages.
- Uses an AI agent to understand the intent behind the question.
- Uses live web search tools to gather current information.
- Responds to the user with accurate, up-to-date information.
- Keeps context through memory to support multi-turn questions.

## Typical use case

This workflow is designed for assistants that answer questions using real-time web information rather than only static knowledge.
