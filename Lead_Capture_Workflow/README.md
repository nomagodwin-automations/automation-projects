# Lead Capture Workflow

This project folder contains the documentation for the lead capture automation.

## Workflow asset

The live workflow file for this project remains in the repository root as:

- `../Lead_Capture_Workflow.json`

## What this automation does

- Triggers on Tally form submissions.
- Normalizes the incoming field values into clear lead fields.
- Checks whether required values such as name and phone are present.
- Appends valid submissions to a main lead tracking sheet.
- Records incomplete or invalid entries in an error sheet.

## Typical use case

This is used by sales and marketing teams to capture and organize leads from landing pages and customer forms.
