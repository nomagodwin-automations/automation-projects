# Lead Capture Workflow

This folder contains the Lead Capture Workflow and its project documentation together.

## Files

- `Lead_Capture_Workflow.json` — the workflow export for this automation.
- `README.md` — overview of how the workflow operates.

## What it does

- Triggers from Tally submissions.
- Captures personal and service requests.
- Validates required fields.
- Saves valid leads to a tracking sheet.
- Sends invalid submissions to an error log.

## Typical use case

This automation is used to collect and qualify new leads from online forms and landing pages.
