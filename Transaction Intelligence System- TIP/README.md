# Transaction Intelligence System - TIP

This folder already contains the project assets for the Transaction Intelligence System, and the project documentation is kept in the same project folder.

## Files

- `index.html` — main user interface.
- `tip-frontend.css` and `tip-frontend.js` — styling and interaction logic.
- `backend/` — n8n workflow assets for identity, upload, and error handling.
- `README.md` — project overview and workflow description.

## What it does

- Collects a user’s name and phone number.
- Accepts a PDF bank statement upload.
- Extracts transactions with Gemini and converts them into structured financial data.
- Produces a story-based summary of spending patterns and financial behavior.
- Shows transaction details with category analysis and downloadable reports.

## Typical use case

This automation is designed for personal finance intelligence and statement analysis with AI-assisted storytelling.
