# Real-Time Web Search Agent

This project folder contains the documentation for the real-time search assistant.

## Workflow asset

The live workflow file for this project remains in the repository root as:

- `../Real-Time Web Search Agent (2).json`

## What this automation does

- Receives Telegram messages from a user.
- Uses a language model agent to interpret the question.
- Uses live web search tools to answer current questions.
- Provides conversational replies with memory support.
- Sends the final answer back to the user in Telegram.

## Typical use case

This is used for a real-time assistant that answers questions using fresh online information instead of only static knowledge.
